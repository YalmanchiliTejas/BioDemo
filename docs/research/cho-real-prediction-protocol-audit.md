# Real CHO prediction protocol, 28 October 2026

Job: evaluate whether the same AI predicts real measured cultivation values better when given a fitted mechanistic model. This is separate from simulated operating decisions and simulated recipe transfer.

Source: [author-published CHO cultivation dataset](https://zenodo.org/records/20829178). Original workbooks contain offline viable-cell counts in cells/mL and glucose in g/L. We use those measurements directly, not interpolated aligned reference CSVs. Cell counts are divided by 1,000,000 for million cells/mL; glucose is unchanged. Every value retains workbook, sheet, cell and time coordinates; workbook hashes accompany the experiment.

Model choice: batch CHO-K1 cultures need batch balances. SMPL's continuous reactor/separator is inappropriate here. The declared simple model uses glucose-limited Monod growth, death and a glucose balance. Published CHO mechanistic/hybrid work supports this model family, including [Bayer et al., 2023](https://onlinelibrary.wiley.com/doi/full/10.1002/biot.202200381). That literature supports the family, not accuracy or calibration for these workbooks. Missing other nutrients, inhibition, environmental variation and nonconstant kinetics can make this approximation wrong. Optimizer convergence does not establish parameter identifiability.

Split: EXP001..009 batch conditions, two reactors per condition. Fold=(EXP number−1)%3; both reactors and all their future measurements are withheld from fitting. Three fixed fit initializations, fixed bounds, no test-label hyperparameter selection. Fitting uses only other conditions through120h. Test conditioning uses each held-out culture's measurements through72h and fixed fitted parameters; it does not refit to later observations. The two AI arms receive identical raw training histories and held-out prefixes. Only B receives the mechanistic forward tool.

Targets: first actual offline value within96..120h for each field, at its original timestamp. Two EXP009 reactors have no glucose measurement in this window and are excluded from the paired primary analysis, with a receipt. Their measurements can be training evidence when another fold is held out. Thus16 scored cultures span eight conditions. Six fed-batch cultures are excluded because available feed composition/planned nutrient forcing is insufficient for a defensible batch balance. No future recorded feed is treated as pre-known. There is no antibody-titer target in this dataset.

Metrics: separate physical-unit MAE for viable cells and glucose; paired errors also normalized by positive training medians, avoiding near-zero glucose MAPE. Two AI session repetitions per culture measure model-session variability, not extra biological replication. Bootstrap by experimental condition, keeping both reactors and repetitions together. Intervals are descriptive: folds overlap in training data and only eight scored conditions exist. This is a retrospective public-data holdout, not prospective validation; unknown model pretraining contamination cannot be excluded.

A simple alternative was empirical extrapolation from the current culture history; a more ambitious alternative was a richer nutrient/metabolite or hybrid model. The selected batch balance makes its assumptions inspectable, while a richer model would need additional inputs and a separate selection protocol. The AI-alone arm can derive its own empirical forecasts from exactly the same raw data. This benchmark preserves source evidence without changing application workflows or systems of record. No measured human time savings, manufacturing intervention success, regulatory validation or real-site tech transfer is claimed.
