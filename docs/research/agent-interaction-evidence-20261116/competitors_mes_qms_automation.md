## KQ1. Autonomous multi-step agents, or prompt-in / draft-out assistants?

### Takeaway
Documented execution without a user at the keyboard exists at two vendors: Veeva (customer-configured workflow-task agents run by an hourly job; none specific to Quality) and Tulip (beta agents invoked from automations that write table records). Honeywell and Dassault claim autonomous agents without public documentation. Everything else whose behaviour is described is user-invoked Q&A or a draft that a person reviews.
