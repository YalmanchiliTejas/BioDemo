# External datasets for physical-model agent evaluation

Checked 27 October 2026 against first-party repository records and original papers. This is a source shortlist, not a completed dataset qualification or agent evaluation.

## Executable source links: original IndPenSim, Python port and freeze-drying

- **Original IndPenSim MATLAB distribution:** [Industrial-scale Penicillin SimulationV2](https://www.mathworks.com/matlabcentral/fileexchange/49041-industrial-scale-penicillin-simulationv2), uploaded by original author Stephen Goldrick; page identifies version 2.0.1 and a 100,000-L penicillin fermentation model. Its download link leads to MathWorks sign-in. The older project website returned HTTP 502 during this check, so use this author-owned distribution to inspect the executable source. [Original model/validation paper](https://www.sciencedirect.com/science/article/pii/S0168165614009377).
- **PenSimPy Python port:** [original repository](https://github.com/Mohan-Zhang-u/PenSimPy), with an [SMPL-maintained fork](https://github.com/smpl-env/PenSimPy). README describes recipe-editable control examples and reliance on the fastodeint C++ ODE binding. Treat the MATLAB implementation and this port as one model family, not independent evaluators. No local rerun or numerical parity qualification was performed for this source search.
- **LyoPRONTO freeze-drying:** [official LyoHUB source](https://github.com/LyoHUB/LyoPRONTO), [original paper](https://link.springer.com/article/10.1208/s12249-019-1532-7). The official repository provides Python simulation/optimization of freezing and primary drying, YAML examples, tests and code. This is relevant to temperature, endpoint and operating-condition comparisons; it does not itself establish receiving-site transfer validity or final product quality. Its equations and assumptions must be considered when assessing independence from our current model. No installation or execution was performed in this search.

## Real freeze-drying: De Montfort University Telstar process logs

Geoffrey Smith (2025), [Process logs from the Telstar freeze-dryer](https://figshare.dmu.ac.uk/articles/dataset/Process_logs_from_the_Telstar_freeze-dryer/29285027), DOI [10.21253/DMU.29285027.v1](https://doi.org/10.21253/DMU.29285027.v1). The university's record describes recorded shelf temperature, chamber pressure, condenser temperature and product-probe temperatures. Its [first-party API metadata](https://api.figshare.com/v2/articles/29285027) confirms public access, downloads enabled, CC BY 4.0, and a 5,473,190-byte `Process logs.xlsx` workbook with a supplied and computed MD5. [Direct workbook download](https://ndownloader.figshare.com/files/55277444). File-level accessibility and metadata were verified; workbook contents have not yet been inspected or mapped.

The associated original study is Wijesekara et al., [An Application for Through-Vial Impedance Spectroscopy (TVIS) in the Qualification of the Pirani-Gauge Assessment of the Ice Sublimation Endpoint](https://pmc.ncbi.nlm.nih.gov/articles/PMC12736985/), *Pharmaceutics* 17(12):1542 (2025), DOI 10.3390/pharmaceutics17121542. It reports laboratory freeze-drying of mannitol and BSA-containing formulations at different vial loads, recorded process data every two minutes, and TVIS-derived endpoint estimates. Those endpoints use a retrospectively selected plateau interval and a 2.2-RMSD threshold; the authors discuss subjectivity and limited generalizability. These are experimentally grounded reference estimates, not exact universal ground truth. The paper refers to raw-data Excel files in its [supplementary Figshare project](https://figshare.com/projects/Supplementary_materials_for_Research_Article_Wijesekara_et_al_2025_Pharmaceutics/251009). The project API independently confirms the process-log workbook and a separate figures PowerPoint; standalone raw TVIS time-series workbooks have not been verified.

**Suggested use (inference):** give both agent arms the same early-cycle process records and material/equipment context; withhold later records and study conclusions, then evaluate temperature forecasts and drying-endpoint estimates on separate complete runs or conditions. Check whether our tool's model assumptions apply to these formulations before using it. This is a relevant real-data test of prediction, uncertainty and endpoint interpretation. It cannot reveal the outcome of every operating change an agent might propose, and it does not supply a broad root-cause benchmark or evidence of commercial batches saved. Dataset is small and public; a completely unseen-to-model guarantee is unavailable.

## External synthetic benchmark: IndPenSim

Stephen Goldrick (2019), [Data for: Modern day monitoring and control challenges outlined on an industrial-scale benchmark fermentation process](https://data.mendeley.com/datasets/pdnjz7zz5x/2), DOI [10.17632/pdnjz7zz5x.2](https://doi.org/10.17632/pdnjz7zz5x.2), CC BY 4.0. The depositor explicitly identifies it as data generated by a mathematical simulator of a 100,000-L penicillin fermentation system. It contains 100 batches and process/Raman measurements, approximately 2.5 GB. Batches 1–30 use recipe control, 31–60 operator control, 61–90 advanced process control, and 91–100 contain faults. The first-party record links the author's [download/plot notebook](https://github.com/StephenGoldie/indpensim-notebook) and original simulator publications.

**Suggested use (inference):** externally authored monitoring and forecasting cases; an executable simulator could additionally support matched intervention experiments after numerical and interface qualification. This reduces dependence on our own invented scenarios, but it remains synthetic evidence. Fixed historical trajectories alone do not establish what an unobserved intervention would have done. Hide fault-revealing batch numbers, PAT-control fields, future product concentrations and published outcome tables when constructing an agent-facing evaluation. The existing project has already explored IndPenSim, so it should not be called a pristine unseen test set.

## Real CHO cultivation time series: OWL University / Zenodo

Uhlendorff et al., [Dataset Based on Chinese Hamster Ovary (CHO) Cultivations including Turbidity, Permittivity, O2 and CO2 Measurements](https://zenodo.org/records/20829178), DOI 10.5281/zenodo.20829178, describes 24 CHO-K1 cultivations at 0.55–0.8 L working volume, lasting 161.5–328.5 hours, with 38 continuous inline and 10 offline variables. The record provides `Dataset.zip` (227.6 MB). The repository's existing `backend/benchmarks/cho/source_manifest.json` identifies this exact source and records matching published/archive MD5 values; `dataset_profile.md` documents 12 source workbooks covering paired reactors, 48 aligned CSVs, process-control channels and offline cell/metabolite measurements. Source-page opening was rate-limited during this check; the indexed first-party record and existing source manifest agree on source identity and dataset description.

**Suggested use (inference):** evaluate prediction of withheld later oxygen, cell or metabolite measurements across whole held-out experimental conditions. Select targets supported by available physical-model inputs; our current small oxygen tool is not automatically a CHO growth model. This dataset is already used in the project, so prior development exposure must be disclosed. Cultivation measurements alone do not provide verified root-cause labels or outcomes for arbitrary new interventions. Preserve raw versus publisher-aligned reference distinctions.

## Real controlled mixing experiments: University of Stuttgart

Barczyk et al., [Data for: Scale-down bioreactors reveal that prolonged mixing times deteriorate the performance of antibody-producing Chinese hamster ovary cells](https://darus.uni-stuttgart.de/dataset.xhtml?persistentId=doi:10.18419/DARUS-6466), DOI 10.18419/DARUS-6466, published 24 September 2026, CC BY 4.0. The first-party record provides public CSV figure-data files for experiments with antibody-producing NISTCHO cells in 3-L bioreactors. Reference, single multi-compartment and porous downscale systems vary mixing conditions; measurements include mixing times, viability, viable cell density, glucose, lactate, antibody concentration and glycosylation. File descriptions identify biological duplicates and their variability. The downloadable material is a small collection of figure-data tables, not a large historian export; file contents have not been independently audited in this search.

**Suggested use (inference):** an externally designed test of whether agents recognize and explain measured performance differences under altered mixing conditions. Stronger experimental grounding for a specific scale-down question than our authored fault labels, but limited sample size and scope. It cannot establish the result of every agent-selected intervention; a mixing-aware model would need separate development and qualification.

## Recommended next step

Start with the real Telstar logs for the existing freeze-drying tool, and use the existing CHO data for a separately scoped oxygen/forecasting task after input-coverage checks. Freeze whole-run/condition splits before tuning, keep later measurements and papers' results unavailable to the agent, and compare both arms against measured outcomes. A public dataset may already be present in a model's training data; isolation prevents live answer lookup but cannot certify absence of memorization. Keep externally simulated intervention experiments separate from real-data prediction results.

## Evaluation boundary

For real recorded data, score only observable predictions, traceable explanations and externally supported findings. Do not grade an unexecuted recommendation as successful using its own forward model. An independently frozen batch/condition split, withheld future records and outcome-bearing metadata, and scientific review are needed before interpreting an A/B difference. Prospective intervention outcomes require additional experiments or a separately qualified external simulator.

## What evidence supports simulator quality?

The original IndPenSim publication, Goldrick et al., [The development of an industrial-scale fed-batch fermentation simulation](https://www.sciencedirect.com/science/article/pii/S0168165614009377), *Journal of Biotechnology* 193:70–82 (2015), DOI [10.1016/j.jbiotec.2014.10.029](https://doi.org/10.1016/j.jbiotec.2014.10.029), reports comparison with ten real 100,000-L penicillin batches. Recorded manipulated variables were supplied to the simulator; predicted outputs were compared with measured online/offline process variables. The original implementation was MATLAB. This is empirical support within the studied process and operating histories. It does not establish accuracy for every agent-selected control change, other organisms or equipment, nor numerical equivalence of later ports.

Our executable integration is a distinct chain: [the local adapter](../../backend/benchmarks/autonomous/simulator.py) constructs a `pensimpy.peni_env_setup.PenSimEnv` environment and applies additional observation/action boundaries. The [recorded benchmark methodology](../case_studies/benchmark_methodology.md) states that all full episodes failed the numerical gate/time budget and optimization scores remain `not_evaluated`. Upstream publication evidence therefore must not be presented as qualification of this local integration. No new simulator execution or repair was performed for this source review.

**Required evidence before using the local simulator as an examiner (recommendation):** pin the exact implementation/dependencies; reproduce upstream reference trajectories under matched inputs; verify physical bounds and balances plus complete-run stability and repeatability; compare held-out measured trajectories with prespecified tolerances; test plausible intervention responses within a declared operating range; and obtain independent process-engineering review. Recheck after changing equations, solvers, units, controls or wrappers. Qualify prediction and intervention uses separately: historical agreement alone cannot establish previously unobserved causal effects.

## Executable simulator links: cell culture and mAb manufacturing

**SMPL mAbEnv — the stronger published mAb benchmark candidate.** The [official source repository](https://github.com/smpl-env/smpl) currently redirects to [Mohan-Zhang-u/smpl](https://github.com/Mohan-Zhang-u/smpl). See the original [NeurIPS 2022 paper](https://openreview.net/forum?id=TscdNx8udf5), its accessible [author manuscript](https://arxiv.org/html/2206.08851), [mAbEnv documentation](https://smpl-env.github.io/smpl-document/mabenv.html), and [implementation/API documentation](https://smpl-env.github.io/smpl-document/_modules/smpl/envs/mabenv.html). This is an executable action-to-next-state environment for continuous mAb production, combining an upstream bioreactor and recycle separation with downstream capture; it includes cell, metabolite, mAb and temperature states and example MPC/EMPC control. The paper's appendix specifies dynamics and references, which make its assumptions inspectable. It is a relevant candidate for testing predictions and comparing simulated control outcomes; it is not an off-the-shelf validated technology-transfer model.

The paper reports industrial-data-informed model development generally, but also explicitly identifies incomplete process variability, optimistic state accessibility, incomplete constraints, and simulator exploitation outside reliable regions. This review did not identify an independently held-out, plant-transfer validation establishing that its complete mAb environment predicts a new receiving site. The documentation also acknowledges possible numerical/controller scaling problems and downstream parameters modified for scale-up. Pin and test a particular implementation before treating its outcomes as an examiner. An external implementation reduces shared code with our tool; common equations and assumptions still limit scientific independence. Sources: [original paper, Sections 2–3.6 and Appendix A.3](https://arxiv.org/html/2206.08851), [maintainer's model and simulation documentation](https://smpl-env.readthedocs.io/en/latest/mabenv.html).

**CC-Sim — exploratory configurable CHO simulator.** [DustinSands/CC-sim](https://github.com/DustinSands/CC-sim) includes a macroscopic CHO model, batch/fed-batch/perfusion reactor setups, controls, assay errors and randomized cell parameters. The author describes a runnable default 2-L fed-batch example and explicitly states that product-quality correlations are incorrect. This makes it useful for inspecting richer observation/control interfaces, but not a defensible product-quality or technology-transfer outcome judge without new validation. No new execution, trajectory comparison or experimental qualification was performed here. Source: [author's README](https://github.com/DustinSands/CC-sim/blob/master/README.md).
