# Benchmark limitations and remaining work

The CHO parser covers every original workbook. A separate fixed-format normalization reconstructed full inline and offline trajectories, with 10,986,364 of 10,996,791 comparable values (99.905%) within the documented normalized tolerance against publisher alignment; 497 reference values had no counterpart. This is a reconstruction result, not an autonomous investigation result. The one-pass path now computes bounded source-derived sheet summaries, but its full model run was interrupted and has no published score. These summaries discard some trajectory detail. The pipeline still does not score causal relevance, calculate objective process-comparison statistics from model output, or establish causal explanations from the measured variables. A controlled workbook perturbation is generated and parsed, but semantic consistency is not yet scored.

The Fresenius v2.1 generator creates CSV, XLSX, text PDF, image-only scanned lab reviews, discrete process-event charts and a fixed UTC-07 lab review export. It does not produce richer trajectories; chart points are recorded events, with no interpolation. Its direct record IDs make identity recovery easy for a conventional parser. The existing agent scores were measured on the earlier v1 export package and must not be assigned to v2.1. Both versions are derived from the same synthetic canonical observations, not actual confidential factory records.

The common interface exists, but the existing RLM consumes structured factory records and has no raw-source adapter. The single-pass LLM baseline was run on Fresenius snapshots. A three-run first-signal repeat under the final isolation profile cited 2, 2 and 5 records; pairwise overlaps were 1.0, 0.4 and 0.4. This small sample shows variation in evidence selection. Action quality, hypothesis contradiction coverage and full-root-cause claims remain unmeasured. No human baseline has been observed; manual preparation time and claimed labor savings are not quantified.

The scored CLI uses a macOS sandbox that denies known evaluation roots, the original mixed-content CHO archive, legacy simulation data, repository reports and documentation. It also restricts accepted input package paths. This is a targeted denylist, not a general read-only allowlist over every filesystem path. Denial probes and package audits check the known leak paths, filenames, timestamps and known hidden/public outcome phrases across CSV, XLSX, PDF and text; they cannot prove the absence of every semantic leak. The current generator's historical snapshots and temporal store prevent later records and later field values from entering earlier tasks.
