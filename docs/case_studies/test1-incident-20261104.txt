Conclusion

Both reported unavailable requests reached the model and received responses
that passed the configured output validation. The application then withheld
them because it mistook another conversation's progress for changed evidence.
This establishes an application failure, not the correctness of the withheld
model answers. Local fixes require deployment and a deployed retest.

Local changes

1. Discovery labels depend on original instruction evidence, including saved-
   work search artifacts. Inspecting an actual saved reply still checks its
   record revision. Real manufacturing evidence changes still invalidate work.
2. A genuine evidence change during inference now reports an evidence check
   and a retry path instead of incorrectly describing a connection outage.
3. After Stop acknowledgment, a late workspace read or action-draft creation
   cannot persist and attach a new result: cancellation is rechecked inside the
   same transaction as persistence and attachment. Existing artifacts survive.
4. Stop displays its pending acknowledgment per turn, including when polling
   observes cancellation before the Stop response arrives.
5. The failed Northfield import recorded:
   'cmo_run_stages 0: elapsed_seconds cannot change after it is recorded'.
   PostgreSQL extra_float_digits=0 rounded unchanged timing values on reads.
   Transactions now request lossless float output. Exact immutability remains
   enforced, including rejection of a one-bit changed timing value.
6. A separate reproduced gateway defect is also corrected: request-specific
   output-limit and HTTP 400 failures no longer disable the model profile for
   unrelated requests. Actual outage/auth/timeout/rate-limit cooldowns remain.
   Model selection, qualification, inference limits and retry caps are unchanged.

Setup and retained limitations

F-2408 is part of a separate demo tenant's seed, not automatically provisioned
into new organizations. Test1 had no evidence metadata matching that identifier.
Its failed Northfield public delivery is a different dataset. Zero connected
sources alone does not mean zero evidence; Test1 had 92 evidence records,
including saved user-instruction evidence.

Historical runs retain their recorded dependency manifests and warnings; these
were not silently rewritten. Rerun affected work after deploying the fix.
An in-flight external model/solver call can continue until it returns; Stop is
not a guarantee that external computation or billing ceases instantly. The new
atomic rollback tests specifically cover workspace results and draft proposals;
other scientific services can create internal records before attachment checks.

The route qualification badge remains accurate. Passing host tests does not
qualify the model, validate manufacturing decisions, or prove long-horizon skill.
No new paid model evaluation or manufacturing action was run in this repair.
