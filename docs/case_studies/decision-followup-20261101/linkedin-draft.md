# LinkedIn draft - based on completed measurements

Does giving a manufacturing agent a mechanistic model actually improve its decisions?

We tested the same Modal GLM-5.3 agent with and without an imperfect process model, using identical evidence and a feasibility-first decision policy.

In 24 prespecified simulated receiving-process scenarios, we recorded 10/24 correct decisions with GLM alone versus 23/24 with GLM plus the mechanistic model.

Constraint-violating operating decisions: 14 without the model, 1 with it. The paired difference in correct-decision rate was +54.2 percentage points (descriptive 95% interval: +33.3 to +75.0).

Model access improved constrained decisions in this simulated cohort.

The conventional model-only selector also scored 23/24; added agent value over that selector was not demonstrated. These are synthetic process outcomes using a shared mechanistic equation family, including deliberately mismatched receiving conditions. They do not establish real manufacturing performance, product quality, or avoided losses. The earlier real CHO forecast comparison did not show benefit from the selected model.

We're reporting the mixed evidence and retained failures because predictive accuracy and better engineering decisions need to be demonstrated separately.
