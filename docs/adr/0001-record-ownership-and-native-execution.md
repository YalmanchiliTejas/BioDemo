# Explicit record ownership and optional native execution

BioDemo will coordinate work across existing systems and keep an explicit authoritative owner for each record class and site. Native manufacturing/laboratory execution is separately enabled with intended-use qualification and assigned ownership. This supports the complete life-sciences offering while avoiding accidental duplicate official records or an unrequested MES/LIMS migration; the cost is explicit integration and reconciliation semantics. See D02 and D16 in the [decision log](../product/life-sciences-platform/decision-log.md).
