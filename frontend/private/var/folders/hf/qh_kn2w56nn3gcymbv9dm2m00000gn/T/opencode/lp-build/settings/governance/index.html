DCS zero-writeback guardrail

Locked
LOCKED_READ_ONLY
  • No user, role or agent can write to DCS, PLC or MES from this platform.
  • Connectors are provisioned with read-only service accounts; there is no write code path to enable.
  • Changing this requires a separate, validated integration project under site change control — not a setting.

Why: process control changes are safety-critical and must go through the site’s own validated systems and approvals.
