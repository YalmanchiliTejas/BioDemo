Platform safety boundary

  • All connectors use read-only service accounts; no write paths to MES, DCS/PLC, LIMS, QMS or ERP.
  • Agent outputs are drafts or proposals, stored separately from source records.
  • Every proposal names its required human approvers; approval is recorded with e-signature meaning.
  • Each run logs tool versions, inputs and outputs to the audit trail. Governance settings
