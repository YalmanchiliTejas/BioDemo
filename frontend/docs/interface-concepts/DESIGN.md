# Interaction concept lab

Preserve the existing application at `/`. The isolated, browser-local prototype lives at `/concepts` and never calls the production API or Prime runtime.

## Design plan

Shared palette: porcelain `#f7f9fa`, ink `#19352f`, muted slate `#677772`, botanical green `#32684f`, evidence blue `#5375a8`, caution ochre `#94651f`. System sans-serif for operational controls, Georgia for the ambient teammate's editorial introduction. Left-aligned content; tabular figures for scientific measurements.

- A: spacious daily brief → expandable investigation → review dialog. A single priority finding anchors an otherwise quiet page. Responsibilities and developments replace KPI cards.
- B: full-width scientific workbench, narrow investigation index, central chart/table, contextual reasoning panel. Evidence leads; secondary tools appear through tabs.
- C: simulated existing historian occupies the screen. A compact, dismissible companion opens in place and escalates into a focused evidence dialog. Preserve the engineer's host context.

Plan critique: three differently colored dashboards would not meet the brief. Different information architectures and transitions are required. Keep a small shared evaluation bar outside the prototypes, and share evidence and review primitives to make comparisons fair. Avoid a chat transcript, fake autonomous actions, generated confidence percentages, or decorative agent animation.

## Scientific boundary

All values, connector records, people, findings, and activity are invented fixtures. No backend request, production monitoring, QMS write, sample request, or physical process change occurs. The illustration concerns penicillin fermentation, not an authentic CHO dataset. Lower dissolved oxygen coincides with lower product concentration; causation, contamination status, and final yield remain unknown. Missing assay results are absent, never zero. A review receipt is local prototype state, not a GMP signature.
